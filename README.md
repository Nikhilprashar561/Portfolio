# Nikhil Prashar — Developer Portfolio

A minimal, business-class personal developer portfolio for Nikhil Prashar built with Next.js (App Router), TypeScript, Tailwind CSS, and Aceternity UI components.

## Features

- **Minimal & Luxury Aesthetics**: Warm off-white and alabaster palette with subtle stone tones and refined typography (Plus Jakarta Sans).
- **Aceternity UI Components**:
  - `Spotlight`: Ambient beam illuminating the hero section.
  - `FlipWords`: Dynamic text rotation in the headline.
  - `CardSpotlight`: Mouse-tracking interactive glow on project cards.
  - Radial-masked geometric grid background.
- **Projects Showcase**: Clean 3-column card grid highlighting key full-stack applications with direct GitHub and demo links.
- **Skills Matrix**: Categorized tech stack (Languages, Frontend, Backend, Databases, Tools & DevOps).
- **Interactive Scheduling Modal**: Integrated meeting request flow with time slots, topic selection, and calendar invite dispatch.
- **Direct Contact Form**: 3-field contact form with client and server-side validation, spam protection, and Resend integration.
- **WhatsApp Integration**: Instant chat link with prefilled message (phone number hidden).

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (Turbopack, App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans & JetBrains Mono

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local dev server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Production build:**
   ```bash
   npm run build
   npm run start
   ```
